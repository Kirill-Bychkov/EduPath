# EduPath: учись и развлекайся

EduPath — мобильное образовательное приложение для изучения языка программирования JavaScript. Оно создано как доступный, автономный и интерактивный инструмент для пользователей разного уровня подготовки.

## ✨ Основные особенности
- 📚 Полностью *офлайн-режим* — обучение без постоянного подключения к интернету
- 🖥️ *Интерактивные уроки* с анимацией, практическими заданиями и тестами
- 🎮 *Геймификация* — достижения и мини-игра для мотивации
- 🌍 *Русскоязычный интерфейс*
- 💡 *Бесплатный доступ* ко всем материалам

## 🎯 Для чего это приложение
EduPath разработан для начинающих программистов, студентов и самоучек, которые хотят изучать JavaScript в удобном формате и в любое время, независимо от наличия интернета или платных курсов.
